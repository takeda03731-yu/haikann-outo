Excelの配管データをもとに、
DXF形式の配管略図を自動生成する業務支援ツールです。
建設業の配管工事業者向けのツールです。
毎日の工事日報に必要な、配管長の略図をExcelから言葉を読み込んで作ることができます。
測点のミス防止・作業時間の短縮を図ることができます。
使い方は、データフォルダにあるExcelデータを入力して、constants.pyに保存箇所を直して、main.pyで実行すればいいです。
DXF形式で、配管長の略図が生成されます。
Excelデータの使用材料の名称で略図が生成されるので、決まった言葉でないと生成できないですが、それさえ把握すれば使えます。
Excelの材料追加で、使用材料の名称を固定して使いやすいように改良する予定です。
